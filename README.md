# МЦ-32 — админ-панель

Локальная панель клиники на Next.js и HeroUI. Сервера пока нет: врачи, прайс, расписание, акции, фразы и учётные записи хранятся в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).
